# SWWB 練習ツール

Shadowverse: Worlds Beyond の **マリガン練習** と **盤面再現** をブラウザで動かす個人用ツールです。サーバーは無く、ルールエンジン（Rust → WebAssembly）がブラウザの中で動きます。

公開ページ: https://uruurus15.github.io/swwb-practice/

## できること
- **マリガン練習**: デッキを選んで最初の手札を配り、マリガン（入れ替え）を何度でもやり直せます。やり直すたびにシード（山札の順序）が変わります。履歴つき。
- **盤面再現**: お互いの手札・PP・リーダー体力・場のフォロワー／アミュレット（攻撃力・体力・進化・付与キーワードなど）を指定して、その局面から遊べます（相手はルールベースボット）。盤面は保存・コード出力できます。
- **対戦**: ルールベースボットとの練習対戦（一手戻る、デッキ編集つき）。
- **デッキ一覧**: 画面右端の「デッキ」タブで開閉できます。対戦中は山札の残り枚数も出ます。
- **デッキ編集**: 40枚・同名3枚まで・自クラス＋ニュートラルの自作デッキを保存できます。

## 注意
- 保存したデッキ・盤面は、そのブラウザの localStorage にだけ残ります（他のブラウザ・端末とは共有されません）。
- カードの効果文は右クリック（手札はクリック）で見られます。タッチ端末では右クリックができません。
- 実装済みのカードだけを扱います（ローテーションの人気デッキ18種に出るカードと、そのトークン）。ルールの解釈には未確認の仮定が含まれます。
