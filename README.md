# SWWB 練習ツール

Shadowverse: Worlds Beyond の **マリガン練習** と **盤面再現** をブラウザで動かす個人用ツールです。サーバーは無く、ルールエンジン（Rust → WebAssembly）がブラウザの中で動きます。

公開ページ: https://uruurus15.github.io/swwb-practice/

## できること
- **マリガン練習**: 対戦画面と同じ配置で、ゲーム開始時のマリガンだけを何度でもやり直せます。
  - 左にデッキ一覧（常時表示。手札にあるカードは緑）、右の丸ボタン（マリガン確定 / もう一度。Enter でも可）、履歴つき。やり直すたびにシード（山札の順序）が変わります。
  - マリガン後は **山札の並び（上から）** が見えます。「画像」表示と「一覧」表示を切り替えられます（選んだ表示は記憶されます）。戻したカード・引いたカードも見比べられます。
- **自動マリガン確認**: マリガンのルールを設定して、「自動マリガン（10回）」で、新しいシードの初期手札 → ルールどおりのマリガン を 10 回くり返します。各回の初期手札・マリガン後の手札・キープの理由・ルールに入れたカードの手札/山札の位置・山札の並び（上から）が見られます。
  - **単キープ**（4枠）: そのカードを 1〜3 枚までキープ。
  - **セットキープ（基本）**（5セット）: 基本のカードが手札にあれば基本をキープし、セット側（5枠、それぞれ 1〜3 枚まで）もキープ。
  - **セットキープ（特殊）**（5セット、4枠のうち 2 枠以上）: 埋めたカードが手札にそろったらキープ。
  - ルールに当たらないカードはすべて入れ替え。同じカードを複数のルールがキープさせるときは、いちばん多い枚数を採用。ルールはデッキごとにブラウザへ保存されます。
- **盤面再現**: 対戦画面の配置のまま、お互いの手札・PP・リーダー体力・場のフォロワー／アミュレットを直接編集して、その局面から遊べます（相手はルールベースボット）。
  - 左に**相手と自分のデッキ**が並び、カードを**手札・場へドラッグ**して置けます（クリックで手札に追加。残り枚数つき）。各デッキの「編集」から、デッキ編集を開けます。保存すると、その席のデッキが保存したデッキに切り替わります。
  - 場・手札のカードをクリックすると、右側で攻撃力・体力・進化・付与キーワード・コストなどを編集できます。
  - 🔶 のカードは**関連カード（トークンなど）**を持ちます。選ぶと右側の「関連カード」から、手札・場にそのまま出せます（デッキ列の右クリックの詳細からも）。
  - 置いたカードは、カードの右上の赤い **×** ボタンで消せます（選択中は Delete キー、右の「まとめて消す」で手札・場ごと）。
  - 盤面は保存・コードのコピー／貼り付けができます。開始後は「同じ盤面からもう一度」「盤面を最初から」でやり直せます。
- **対戦**: ルールベースボットとの練習対戦（一手戻る、デッキ編集つき）。
  - 進化・超進化したフォロワーは「進化」「超進化」の札と金／紫の枠で分かり、守護・ドレイン・バリア・オーラなどの常在能力は能力ごとの色で表示します（効果文中の【守護】なども同じ色）。
- **デッキ編集**: 40枚・同名3枚まで・自クラス＋ニュートラルの自作デッキを保存できます。

## 注意
- 保存したデッキ・盤面は、そのブラウザの localStorage にだけ残ります（他のブラウザ・端末とは共有されません）。
- カードの効果文は右クリック（手札はクリック）で見られます。右クリックがない端末では見られません。デッキ列からのドラッグは、マウスと（エミュレーションでの）タッチ操作で確認しています。
- 実装済みのカードだけを扱います（ローテーションの人気デッキ18種に出るカードと、そのトークン）。ルールの解釈には未確認の仮定が含まれます。
